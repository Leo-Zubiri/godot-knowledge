## Credits (documented guidance)
Creative Commons recommends crediting **Title, Author, Source and License** (TASL), linked where possible, with the licence named and linked to its deed; there is "no single best way" if it is reasonable for the medium; for audio/video credit in the work and on a web page; for modified works say what changed and note the original; do not credit only a host site or rely on alt text/metadata alone; music in video is generally an adaptation, so ND-licensed music should not be used that way; CC0 needs no attribution but citing the source is recommended. A game credits screen with TASL lines is consistent with this (our reading).

## Notices
Godot's MIT notice requirement is in [[game-studio-godot-ecosystem-free-resources]]; notice practice for other MIT/OFL/Apache components was **not found** in official guidance (*unverified*).

## Age ratings and privacy — human/legal review
IARC is described as a global, free age-rating system for digital games and apps; the page read named no storefronts or steps. ESRB, PEGI, COPPA and GDPR pages were not read. **No conclusions are drawn; a human decides.**

## Agent can / cannot
An agent can compile a credits list and a draft notices file from the asset registry. Legal sign-off is human.
