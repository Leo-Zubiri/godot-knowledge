- **ISteamMicroTxn (Web API, `partner.steam-api.com/ISteamMicroTxn/`):** `GetUserInfo` (GET v2, "Retrieves details for a user's purchasing info" — country, currency, status); `InitTxn` (POST v3, "Creates a new purchase"); `FinalizeTxn` (POST v2, "Completes a purchase that was started by the InitTxn API"); `RefundTxn` (POST v2, "Tells Steam to refund a user for a purchase. Refunds can only be made for the full value of the original order"); `GetReport` (GET v5, "should be used solely for granting or removing entitlement of an in-game item"); `ProcessAgreement`, `AdjustAgreement` (forward only), `CancelAgreement`, `GetUserAgreementInfo` (subscriptions). **Every call needs `key`, a "Steamworks Web API publisher key with Microtransaction permissions."** "Use ISteamMicroTxnSandbox while testing!" `InitTxn` parameters: `orderid` ("Unique 64-bit ID for order"), `steamid`, `appid`, `itemcount`, `language` (ISO 639-1), `currency` (ISO 4217), `itemid[n]`, `qty[n]`, `amount[n]` (cents), `description[n]` (≤128 chars), optional `usersession` ("client" default or "web") and `ipaddress` (required for web). `FinalizeTxn`/`RefundTxn`: `orderid` + `appid`. Order IDs are 64-bit (string-formatted since v2); for store-initiated subscriptions `orderid` is 0, use `transid`.
- **Microtransactions implementation guide:** flow — game collects the user's Steam ID; **"Your purchasing server initiates a purchase request through the Steam web service on behalf of the Steam client"** (`InitTxn`); "Steam will automatically activate the Steam overlay and present a dialog to the user listing all of the items"; the game registers an `ISteamUser::MicroTxnAuthorizationResponse_t` callback; **"Your purchasing server uses the ISteamMicroTxn/FinalizeTxn API command to complete the transaction"**; "A successful response means that the purchase has been accepted and the items should be granted." "All requests should be sent using HTTP 1.1 GET or POST using a TLS secure connection." The publisher key "is passed with all web server requests and is used to authenticate server requests" (the page does not spell out "never ship it in the client" — *that wording is not on the page*). Sandbox: `https://partner.steam-api.com/ISteamMicroTxnSandbox/*`, "no actual funds will be withdrawn". Refunds: developer-initiated `RefundTxn`; Steam-initiated reversals include orders "refunded by Valve because it was suspected to be fraud", chargebacks and friendly fraud; "your backend should attempt to claw-back items associated with the reversed transaction if at all possible"; "You should be calling this API [GetReport] at least once daily to reconcile settlement updates". Web flow uses `usersession=web` (browser authorization).
- **Steam Inventory Service:** "a set of features that allow a game to enable persistent player inventories without having to run special servers"; item definitions (ItemDefs) configured in Steamworks "describe the possible set of items in your game"; purchases through the web Item Store, a custom in-game store calling `ISteamInventory::StartPurchase`, or a simple purchase page; prices defined in itemdefs; drops via `TriggerItemDrop` with Steam tracking playtime; trading and Community Market. **Security:** "the client can't be trusted (and the keys in a client can always be captured by an attacker)"; a trusted server with a privileged key may grant explicit items only "when the server is the master of the state of the game". Web API reference `IInventoryService` linked, not read (`AddItem`/`ConsumeItem` *unverified*).
- **Steam refund policy (updated 23 Apr 2024):** refunds "within two weeks of purchase and with less than two hours of playtime" for games and software; **in-game purchases:** Valve-developed games refundable within 48 hours if the item was not consumed, modified or transferred; third-party developers "can choose to offer refunds on their items", otherwise in-game purchases in non-Valve games are not refundable through Steam; DLC refundable within 14 days with < 2 hours played since purchase and not consumed/modified/transferred (some third-party DLC marked non-refundable); pre-purchases refundable any time before release; Steam Wallet funds within 14 days if unused; unredeemed gifts within the standard window; "Refunds are designed to remove the risk from purchasing titles on Steam—not as a way to get free games" — Valve may stop offering refunds to users who abuse them.
