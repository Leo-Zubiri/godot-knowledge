Licence deeds are plain-language summaries with no legal value — the full legal code governs. Re-fetch and have a human read the actual terms before relying on any asset.

- **Poly Haven (polyhaven.com/license, read):** all HDRIs, textures and 3D models CC0; commercial use allowed incl. products you sell; credit not required (appreciated); sharing, including in your own work or bundling in a product, allowed; AI training not explicitly addressed (page notes AI researchers use the assets). Site content (logos, renders, text, avatars) is excluded from CC0 and protected; the site ToS prohibits web scraping or data mining without express permission; use of the public API is governed by **separate API Terms hosted on GitHub** (the guessed `ToS.md` path returned 404 — API Terms, rate limits, auth: `unverified`). Per the research agent (README): public API at api.polyhaven.com with a Swagger spec; building on the live API requires a small "Powered by Poly Haven" credit; API code AGPL-3.0.
- **ambientCG (docs.ambientcg.com/license, read):** CC0 1.0 covers all assets including downloadable files and preview renders; commercial use without permission; may copy/change/share and include raw files in a project such as a video game; credit not required (a short credit line is suggested); AI not mentioned. API (docs.ambientcg.com/api, per research agent): v1 `/downloads_csv`, `/full_json`; v2 adds `/categories_json`, `/releases_rss`; v3 `/assets`, `/categories`, `/collections`, `/rss`, `/user`; no rate-limit/auth/usage rules on the page; page itself says the API may not be reliable or stable enough for enterprise use and that one person operates the site.
- **TextureCan (texturecan.com/terms, read):** site states all its PBR textures, graphics and photos are CC0 1.0; commercial use allowed; credit optional; textures may be passed on alongside your own projects and 3D assets, but whether raw texture files may be redistributed **by themselves** (e.g. as a texture pack) is unclear; brand names/logos/copyrighted graphics inside materials are not covered by CC0. Formats and API not stated (only an SBSAR mention on one asset).
- **BlenderKit / Blendkit (blendkit.com/docs/licenses, read):** two licences chosen per asset by the author: **Royalty Free** (commercial use, no credit; may sell derivative works such as a game or scene, but **cannot resell the 3D model itself**, even modified, alone or in an asset pack or level) and **CC0**. Page does not cover collaborators, free vs paid plan differences, or AI; links to a pricing page and a Licensing FAQ (not read). API/programmatic access `unverified` (Blender add-on is the main client).
