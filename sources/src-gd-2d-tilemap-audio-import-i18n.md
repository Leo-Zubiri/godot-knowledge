- **TileMap → TileMapLayer:** `TileMap` is deprecated ("use multiple TileMapLayer nodes instead"); conversion via the TileMap bottom-panel toolbox "Extract TileMap layers as individual TileMapLayer nodes"; deprecated methods — `force_update()` → `notify_runtime_tile_data_update()` and/or `update_internals()`; `get_navigation_map()`/`set_navigation_map()` → `get_layer_navigation_map()`/`set_layer_navigation_map()`. The pages do not say which version made the change ("4.3" is UNV from the docs). **TileMapLayer class:** `tile_set`, `collision_enabled` (true), `use_kinematic_bodies` (false), `rendering_quadrant_size` (16), `physics_quadrant_size` (16; set to 1 for exact cell coordinates from `get_coords_for_body_rid()`), `tile_map_data`, `navigation_enabled`, `occlusion_enabled`, `y_sort_origin`, `x_draw_order_reversed`; methods `set_cell(coords, source_id, atlas_coords, alternative_tile)` (−1 values erase), `erase_cell`, `clear`, `get_cell_*`, `local_to_map`, `map_to_local`, `get_used_cells`, `get_used_rect`, `set_cells_terrain_connect/path`, `fix_invalid_tiles`, `update_internals`, `notify_runtime_tile_data_update`. Pitfalls: updates are batched to end of frame (`update_internals()` for immediate, expensive); serialized coordinates are 16-bit signed (−32768..32767, tiles outside wrap on save); Y-sorting disables `rendering_quadrant_size`; sub-resources in the `TileData` passed to `_tile_data_runtime_update()` are shared with the TileSet (duplicate first); built-in TileMap navigation performs poorly — bake with `NavigationRegion2D`/`NavigationServer2D` and disable layer navigation; stacked 2D navigation meshes on one map cause merge errors. **TileSet:** set tile size before creating the atlas; margin/separation/region changes can remove tiles; changing an alternative tile ID breaks maps; alternatives do not inherit base properties; unmerged atlases are removed unless using Merge (Keep Original Atlases); terrain sets need Terrain Set ≥ 0, IDs start at 0, −1 none, modes Match Corners and Sides / Corners / Sides.
- **Camera2D and pixel art:** no dedicated pixel-art page in the 2D index. Camera2D: `position_smoothing_enabled/speed`, `limit_*`, `limit_smoothed`, `drag_*`, `offset`, `zoom`, `process_callback`, `anchor_mode`, `get_screen_center_position()`, `force_update_scroll()`, `reset_smoothing()`, `align()`; the page mentions physics interpolation and pixel snapping but has no content on either. Settings read from the ProjectSettings excerpt: `rendering/2d/snap/snap_2d_transforms_to_pixel` false, `snap_2d_vertices_to_pixel` false (not recommended together with transform snapping), `physics/common/physics_jitter_fix` 0.5, `rendering/textures/canvas_textures/default_texture_filter` default 1 (value meanings not read). A search claim that `canvas_items` became the stretch default for projects created from 4.7 is single-source UNV.
- **AudioStreamSynchronized (header not reported):** plays sub-streams in sync from the same start; `stream_count` (default 0); `get/set_sync_stream(idx, stream)`, `get/set_sync_stream_volume(idx, volume_db)`; `MAX_STREAMS = 32`; playback ends when the last sub-stream finishes and continues if any sub-stream loops.
- **Import process and images:** `.import` files sit next to source assets (commit them); compiled output in `res://.godot/imported/` (do not commit; default VCS ignore rules exclude it); reimport triggers — Import dock Reimport, resource-type change, source MD5 change, deleting files in `.godot/imported/`; use `ResourceLoader` for imported assets (`FileAccess` works in the editor but breaks after export); `.gdignore` excludes a folder; "Keep File (exported as is)" vs "Skip File (not exported)"; project-wide defaults in Import Defaults; **the page does not cover command-line or headless import**. Image options: `compress/mode` Lossless (2D default), Lossy, VRAM Compressed (3D default), VRAM Uncompressed, Basis Universal; `high_quality` uses BPTC/ASTC and only works with Forward+/Mobile; `hdr_compression` Disabled/Opaque Only (default)/Always; `mipmaps/generate` (~33% more memory); **`mipmaps/limit` "currently has no effect"**; `process/fix_alpha_border` (default on), `premult_alpha`, normal-map invert Y, size limit; pixel art stays Lossless even in 3D. The `rendering/textures/vram_compression/import_s3tc_bptc` and `import_etc2_astc` entries were **not found** in ~300,000 characters of the stable ProjectSettings page; descriptions seen elsewhere conflict between versions — UNV.
- **CSV translations (spreadsheets page):** first column keys (top-left cell ignored), other columns locale codes, underscore-prefixed columns are comments; **since 4.6 `?plural` and `?context` columns** (ideally second) are supported but those strings need manual translation via `tr_n()`/`tr()`; keys unique and case-sensitive; save UTF-8 without BOM; delimiter and compression set in the Import dock then Reimport; imported translations are inactive until registered in the localization settings; fields with commas, line breaks or double quotes must be quoted with inner quotes doubled. `importing_translations` is only an overview with links; pseudolocalization page exists but unread.
- **Compatibility renderer (search summary, UNV):** low-end desktop/mobile and widest hardware range, the web renderer; OpenGL ES 3.0 on mobile and OpenGL 3.3 on desktop; shadowed lights draw in multiple passes; no normal/roughness buffer, no compute shaders, most post-processing unavailable, no internal HDR (banding); docs recommend testing on low-end hardware and offering a graphics options menu. A `system_requirements` page exists (unread).
